# AI Log

This document records how AI tools were used during Project Exam 1.

## AI Tool Used

- ChatGPT

## Project Period

August – September 2026

## How AI Was Used

AI was mainly used as a development and learning support tool during the project.

The main uses were:

- Brainstorming ideas for the store concept, layout and user experience.
- Explaining JavaScript, HTML and CSS concepts.
- Debugging problems in existing code.
- Reviewing code and suggesting small improvements.
- Helping identify accessibility issues.
- Reviewing responsive layouts and suggesting CSS improvements.
- Checking project requirements against the implementation.

## Examples of AI Assistance

Some examples of problems where AI was used for guidance or debugging include:

- Improving the responsive mobile navigation.
- Fixing accessibility issues found with WAVE.
- Adding an accessible label to the product quantity input.
- Improving the product page loading state.
- Handling discounted product prices consistently across the product, cart, checkout and success pages.
- Reviewing responsive layouts for different screen sizes.
- Debugging sessionStorage usage for login, cart and order data.
- Reviewing the project against the requirements in the project brief.

AI was also used to explain why changes were needed so that the code could be understood rather than simply copied.

## Code and Implementation

The main application logic was developed by me.

AI was not used to generate the central API fetching logic, central cart state or the main product rendering logic.

When AI suggestions included code, they were used as small targeted examples, debugging help or modifications to code I had already written. I reviewed and adapted these changes so that I understood how they worked and could explain them.

## Learning

Using AI during the project helped me understand problems faster, especially when debugging JavaScript and responsive CSS.

I also used AI explanations to better understand accessibility, browser storage, form validation and responsive design decisions.

The final implementation was tested manually and adjusted during development.

## AI and Reflection

AI was used as a supporting tool during the development process, mainly for learning, debugging, brainstorming and review.

The use of AI did not replace the development work or decision-making process. I remained responsible for the implementation, testing, design decisions and final result.
